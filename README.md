# Hexil
A pixel art suite capable of non-square pixels, inspired by my desire to draw my favourite flower in my preferred very simple art style, and my very high standards for performance making existing solutions frustrating. Also, making this is my idea of fun.

## This is NOT open-source software!
I am leaving the source code free to _view_, for a couple reasons (I like to show off, and that desire to show off will help keep me motivated to write quality code), but I do _not_ grant license to actually do anything with it, I'm just not hiding it.
